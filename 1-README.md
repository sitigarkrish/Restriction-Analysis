# Restriction Site Analysis Using Python & BiPpython

## Overview

Restriction enzymes are proteins that recognize specific DNA sequences and cleave DNA at precise locations. They are widely used in molecular cloning, restriction mapping, recombinant DNA technology, PCR experiment planning, and various genomic studies. Computational analysis of restriction sites enables researchers to identify enzyme recognition sites within DNA sequences before performing laboratory experiments, saving both time and resources.

This project demonstrates the use of **Python** and **Biopython** to perform restriction site analysis on the **BRCA1 coding sequence (CDS)**. The program reads the DNA sequence from a FASTA file and analyzes it using Biopython's restriction enzyme modules. It performs analysis with both a **single restriction enzyme (EcoRI)** and **multiple restriction enzymes (EcoRI, BamHI, and HindIII)** to identify their recognition sites and corresponding cut positions within the sequence.

The primary objective of this project is to introduce computational restriction site analysis while providing practical experience with Python and Biopython for biological sequence analysis. It also demonstrates how bioinformatics tools can be used to support molecular biology applications by automating the identification of restriction enzyme recognition sites in DNA sequences.
